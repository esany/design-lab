# Merkzettel je Thema

Hier hat jedes aktive Thema des Labors einen Merkzettel (Regel `decisions/0029`). Ein neuer
Chat liest nur den Merkzettel seines Themas. Die Liste der aktiven Themen steht in `stand.md`,
Abschnitt „Themen“.

**Aufbau jedes Merkzettels:**

1. **In Worten, für den Eigentümer:** Wo steht das Thema? Was kommt als Nächstes? Was
   entscheidet er? Welche Fragen sind offen?
2. **Eingeklappt, für die Modelle:** Nummern von Issues und Pull Requests, Lehren und
   Fundstellen.

**Am Ende einer Sitzung:** abgleichen, nur den eigenen Merkzettel fortschreiben, Überholtes dort
entfernen, die Zeile in `stand.md` anpassen. Abgeschlossene Themen kommen nach `archiv/`.
