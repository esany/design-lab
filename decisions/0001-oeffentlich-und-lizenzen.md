# 0001 · Sichtbarkeit und Lizenz

**Entscheidung:** Das Repo ist öffentlich. Code steht unter MIT, Inhalte (Texte, Studien, Bilder) unter CC BY 4.0.

**Begründung:** Öffentlich: Branch-Schutz und GitHub Pages sind kostenlos; Studien und Werkzeuge werden sichtbar und als deine Autorschaft belegt. Offene Lizenzen passen zum Ziel Unabhängigkeit.

**Alternativen:** privat (Branch-Schutz und Pages brauchen dann GitHub Pro); andere Lizenz, z. B. CC BY-NC (keine kommerzielle Nachnutzung) oder alle Rechte vorbehalten.

**Betrifft:** README.md, LICENSE, LICENSE-CONTENT.md

**Deine Entscheidung:** Öffentlich (damit die Website kostenlos und automatisch läuft), aber **keine offene Lizenz — alle Rechte vorbehalten**. Ein Repo ohne Lizenz darf man ansehen, aber nicht weiterverwenden. Eine offene Lizenz kann später jederzeit ergänzt werden. (Chat, 2026-10-27; zwischenzeitlich „privat“, revidiert wegen der Website.)
