# Entscheidungen

Jede strukturelle Entscheidung hat eine Datei mit Status:
**Vorschlag → freigegeben → gültig → abgelöst** (abgelöste bleiben als Historie).

Alle Einträge unten hat der Agent beim Aufbau getroffen, **ohne vorherige Freigabe**.
Sie stehen deshalb auf *Vorschlag*. Prüfe sie einzeln: im Pull Request bei der
jeweiligen Datei kommentieren („ok“, „ändern: …“, „streichen“). Was du ablehnst,
wird zurückgebaut, bevor gemergt wird.
