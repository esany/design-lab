# Entscheidungen

Jede strukturelle Entscheidung hat eine Datei mit Status:
**Vorschlag → freigegeben → gültig → abgelöst** (abgelöste bleiben als Historie).

**Perspektive** (Kopfzeile `perspektive:`, Befund `research/2026-10-modi-und-dokumentation/befund.md`):
`system` = das Labor bauen (Regeln, Prüfungen, Arbeitsteilung, Ablage) · `fach` = Gestaltungswissen
und Methode · `gebrauch` = mit dem Labor ein Werk gestalten. Bei Grenzfällen beide nennen. Die
Einteilung der älteren Einträge nach Titel ist *abgeleitet*, nicht belegt; bei Streit ändert der
Eigentümer das Etikett. Neue Entscheidungen nutzen [`VORLAGE.md`](VORLAGE.md) mit den Abschnitten
**Folgen** und **Alternativen**; ältere bleiben unverändert (Historie).

Der Agent arbeitet im freigegebenen Rahmen selbstständig (0019) und legt nur offene
Punkte als Fragen in Alltagssprache vor (0018). Antworten trägt er hier ein.
