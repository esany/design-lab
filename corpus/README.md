# Korpus

Hier liegen **Verweise**, keine Volltexte: Literaturlisten, Normdaten-IDs,
Links auf offene Sammlungen. PDFs und geschützte Abbildungen gehören nicht in
dieses Repository.

## Quellen, die Agenten bevorzugt nutzen

| Art | Quelle |
|---|---|
| Literatur | Zotero (Web-Bibliothek; optional per MCP angebunden) |
| Personen | Wikidata, Getty ULAN, GND |
| Begriffe | Getty AAT |
| Orte | Getty TGN, Wikidata |
| Werke, Bilder (offen) | Met Open Access, Rijksmuseum, Europeana, SMB-digital |

## Ablage

Eine Datei pro Thema, z. B. `konkrete-kunst.md`:

```markdown
| Titel | Autor:in | Jahr | Zotero-Key / DOI / URL | Notiz |
```

Siehe Skill `belegpflicht`.
